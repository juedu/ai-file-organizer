AI로 파일을 자동 정리하세요

AI가 이미지, 문서, 다운로드 파일을 내용 기반으로 자동 분류하고 이름을 변경합니다. 프로그램을 다운받아 바로 사용하세요!

다운로드 사용 방법 보기

주요 기능

AI가 파일의 내용을 보고 판단합니다

🧠

AI 기반 분류

파일명이 아닌 실제 내용(이미지, 텍스트)을 AI가 분석하여 폴더를 결정합니다.

📝

자동 리네이밍

의미 없는 파일명(IMG_001.jpg)을 내용 기반 설명으로 자동 변경합니다.

🗂

프로파일 시스템

용도별 분류 규칙을 프로파일로 저장. 9가지 기본 프로파일 제공.

🌐

원격 AI 지원

Ollama가 없어도 OK! 원격 서버의 AI를 활용하여 분류합니다. 파일은 내 컴퓨터에서 정리됩니다.

↩

되돌리기 지원

모든 작업은 기록되며 언제든 원래 상태로 복원할 수 있습니다.

🌐

웹 브라우저 UI

별도 앱 설치 없이 브라우저에서 사용. 실시간 진행 상황 표시.

4단계로 간단하게

프로그램 다운로드

서버 연결 설정

설정 페이지에서 원격 모드를 선택하고 API 키를 입력합니다

폴더 선택 & 분류

정리할 폴더를 선택하고 AI 분류를 시작합니다

미리보기 & 실행

분류 결과를 확인한 후 복사 또는 이동을 실행합니다

기본 프로파일

바로 사용할 수 있는 9가지 분류 프로파일

기본 파일 정리파일 종류별 기본 분류
그림 품질 분류퀄리티 기준 분류
이미지 출처 분류출처/용도별 분류
컨텐츠 수위 분류수위/노출 정도별
문서 주제 분류문서 주제/용도별
배경화면 해상도 분류해상도/비율 기준
사진 정리촬영 장면/상황별
다운로드 폴더 정리파일 종류별 정리
밈/짤 정리감정/용도별 분류

다운로드 & 설치

ZIP 파일을 다운로드하고 압축을 풀면 끝!

📥 ZIP 다운로드
# 또는 Git으로 클론:
git clone https://github.com/juedu/ai-file-organizer.git
cd ai-file-organizer

다운로드 후:

# Windows: 더블클릭만 하면 됩니다
start.bat

# Linux / macOS:
chmod +x start.sh && ./start.sh

start.bat을 실행하면 자동으로 가상환경 생성, 패키지 설치, 서버 시작, 브라우저 오픈까지 처리됩니다.
실행 후 설정 페이지에서 원격 모드를 선택하고 서버 URL과 API 키를 입력하세요.
