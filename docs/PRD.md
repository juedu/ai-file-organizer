# PRD: AI File Organizer (FileCleanup)

## 1. 제품 개요

### 1.1 목적
로컬 AI(Ollama)의 Vision-Language 모델을 활용하여 지정된 폴더 내의 파일들을 **사용자 정의 기준**으로 자동 분석, 분류, 리네이밍, 재정리하는 웹 기반 파일 정리 도구.

### 1.2 핵심 가치
- **사용자 정의 분류 기준**: "분류 프로파일"로 어떤 기준이든 자유롭게 정의 (품질, 용도, 장르, 수위 등)
- **AI 기반 지능형 분류**: VL 모델 하나로 이미지 내용까지 깊이 분석
- **자동 리네이밍**: 무의미한 파일명을 사용자 정의 패턴으로 변환
- **안전한 정리**: 미리보기 후 실행, 되돌리기(undo) 지원
- **어디서든 접근**: 로컬(localhost) + 외부 도메인(close-ai.iptime.org) 모두 지원

### 1.3 대상 사용자
- 대량의 이미지/파일이 정리되지 않은 채로 쌓인 사용자
- 자기만의 기준으로 파일을 정교하게 분류하고 싶은 사용자
- 그림, 사진, 다운로드 파일 등을 체계적으로 정리하고 싶은 사용자

## 3. 핵심 개념: 분류 프로파일 시스템

### 3.1 프로파일이란?
**분류 프로파일**은 "어떤 기준으로 파일을 분류할지"를 정의하는 설정 묶음입니다.
사용자가 프로파일을 만들면, AI는 그 기준에 맞게 파일을 분석하고 분류합니다.

### 3.2 프로파일 구성 요소

```yaml
profile:
  name: "그림 품질 분류"              # 프로파일 이름
  description: "그림의 퀄리티 기준"    # 설명

  # 분류할 폴더 목록 (각 폴더에 AI가 이해할 설명 첨부)
  folders:
    - name: "명작"
      description: "전문가급 퀄리티, 구도와 색감이 뛰어남"
    - name: "양호"
      description: "평균 이상, 괜찮은 수준"
    - name: "스케치"
      description: "러프 스케치, 낙서, 미완성"
    - name: "미분류"
      description: "판단 불가"

  # AI에게 보낼 분류 지시 (사용자가 자유롭게 작성)
  prompt: |
    이 이미지의 그림 퀄리티를 평가하세요.
    전문가급이면 "명작", 괜찮으면 "양호", 러프하면 "스케치"로 분류하세요.
    판단이 어려우면 "미분류"로 답하세요.

  # 리네이밍 패턴 (선택)
  rename_pattern: "{folder}_{description}"   # 예: "명작_용을_그린_판타지_일러스트.jpg"
  enable_rename: true
```

### 3.3 프로파일 예시

#### 예시 1: 그림 품질 분류
```yaml
name: "그림 품질 분류"
folders:
  - { name: "명작", description: "전문가급, 매우 높은 완성도" }
  - { name: "양호", description: "괜찮은 수준의 그림" }
  - { name: "보통", description: "평범한 수준" }
  - { name: "스케치", description: "러프 스케치, 낙서" }
prompt: "이 이미지의 그림 퀄리티/완성도를 평가하세요."
rename_pattern: "{description}"
```

#### 예시 2: 이미지 출처/용도 분류
```yaml
name: "이미지 출처 분류"
folders:
  - { name: "직접그린", description: "본인이 직접 그린 그림, 디지털 아트" }

  - { name: "짤_밈", description: "인터넷에서 가져온 재미있는 짤, 밈 이미지" }

prompt: "이 이미지가 어디서 온 것인지, 어떤 용도인지 판단하세요."
rename_pattern: "{folder}_{description}"
```

#### 예시 3: 컨텐츠 수위 분류
```yaml
name: "컨텐츠 수위 분류"
folders:
  - { name: "전체이용가", description: "누구나 볼 수 있는 안전한 이미지" }
  - { name: "약간노출", description: "약간의 노출이 있지만 심하지 않음" }
  - { name: "성인", description: "성인 컨텐츠, 노출이 심함" }
prompt: "이 이미지의 수위/노출 정도를 판단하세요."

```

#### 예시 4: 문서 주제 분류
```yaml

  - { name: "법률계약", description: "계약서, 법률 문서" }

rename_pattern: "{folder}_{description}"
```

#### 예시 5: 종합 파일 정리 (기본 프로파일)
```yaml

  - { name: "사진", description: "실제 촬영 사진" }
  - { name: "그림", description: "디지털 아트, 일러스트, 팬아트" }
  - { name: "문서", description: "PDF, Word, 텍스트 문서" }
  - { name: "스크린샷", description: "화면 캡처" }
  - { name: "동영상", description: "비디오 파일" }
  - { name: "음악", description: "오디오, 음악 파일" }
  - { name: "압축", description: "압축 파일" }
  - { name: "기타", description: "위에 해당하지 않는 파일" }
prompt: "이 파일의 종류와 내용을 분석하여 가장 적합한 폴더를 선택하세요."
rename_pattern: "{description}"
```

### 3.4 프로파일 관리
- 프로파일 생성/수정/삭제/복제
- JSON/YAML 파일로 저장 (`data/profiles/` 디렉토리)
- 기본 프로파일 5개 내장 (위 예시)
- 프로파일 내보내기/가져오기

### 3.5 분류 시 프로파일 선택 흐름
```
1. 폴더 스캔 완료
2. 사용자가 프로파일 선택 (또는 새로 만들기)
3. 선택된 프로파일의 폴더 목록과 프롬프트가 AI에 전달됨
4. AI가 프로파일 기준에 따라 각 파일 분류
5. 미리보기 → 실행
```

## 4. 기능 요구사항

### 4.1 핵심 기능 (P0 - 필수)

#### F1: 폴더 선택 및 스캔
- 사용자가 정리할 대상 폴더를 지정
- 폴더 내 파일 목록을 재귀적 또는 1단계만 스캔
- 스캔 결과: 파일명, 확장자, 크기, 수정일, MIME 타입
- 하위 폴더 목록 감지

#### F2: 분류 프로파일 시스템
- 사용자 정의 분류 프로파일 생성/수정/삭제
- 프로파일별 폴더 정의 (이름 + AI용 설명)
- 프로파일별 커스텀 프롬프트 작성
- 프로파일별 리네이밍 패턴 설정
- 기본 프로파일 5개 내장
- 프로파일은 `data/profiles/*.json`에 저장

#### F3: AI 파일 분석 및 분류
- 선택된 프로파일 기준으로 파일 분류
- **이미지**: base64 인코딩 → VL Vision 기능으로 분석
- **문서(PDF, DOCX, TXT 등)**: 텍스트 추출 → VL Language 기능으로 분석
- **기타**: 파일명 + 확장자 기반 + AI 보조
- AI에게 전달되는 프롬프트: 프로파일의 커스텀 프롬프트 + 폴더 목록 + 파일 정보
- 분류 결과: 대상 폴더, 새 파일명(옵션), 설명

#### F4: 파일 리네이밍
- 프로파일의 `enable_rename` 설정에 따라 활성화
- 프로파일의 `rename_pattern`에 따라 파일명 생성
- 패턴 변수: `{folder}`, `{description}`, `{date}`, `{original}`
- 확장자는 항상 보존
- 파일명 충돌 시 자동 넘버링

#### F5: 파일 재정리 (이동/복사)
- **복사 모드** (기본, 안전): 원본 유지
- **이동 모드**: 원본을 이동
- 프로파일 폴더 자동 생성
- 이름 충돌 해결

#### F6: 미리보기
- 실행 전 모든 변경사항을 미리보기
- 폴더별 그룹핑
- 개별 파일 제외/포함 토글
- 미리보기에서 개별 파일의 대상 폴더/이름 수동 수정 가능

#### F7: 되돌리기 (Undo)
- 매니페스트 파일 기반 되돌리기

### 4.2 보조 기능 (P1 - 중요)

#### F8: 실시간 진행 상황
- WebSocket 기반 실시간 업데이트
- 현재 처리 중인 파일명 + AI 분류 결과 실시간 표시
- 진행률 바, 예상 남은 시간

#### F9: 설정 관리
- Ollama 서버 URL 설정
- AI 모델 선택 (목록 조회)
- 연결 테스트
- 작업 모드 (복사/이동)
- 언어 (한국어/영어)

### 4.3 추가 기능 (P2 - 선택)

#### F10: 필터
- 파일 크기/확장자/날짜 필터

#### F11: 작업 이력
- 이전 작업 이력 조회 + 되돌리기

## 5. 기술 스택

### 5.1 백엔드
- **언어**: Python 3.10+
- **웹 프레임워크**: FastAPI
- **비동기**: asyncio + httpx (Ollama 통신)
- **WebSocket**: FastAPI WebSocket
- **포트**: 5000

### 5.2 프론트엔드
- **HTML/CSS/JS**: 순수 바닐라
- **CSS**: 커스텀 CSS (다크 모드 지원)
- **통신**: fetch API + WebSocket

### 5.3 AI/ML
- **런타임**: Ollama
- **모델**: `huihui_ai/qwen3-vl-abliterated:30b-a3b-instruct`
- **API**: Ollama REST API (`/api/generate`)

### 5.4 파일 처리
- **텍스트 추출**: PyPDF2 (PDF), python-docx (DOCX)
- **이미지 처리**: Pillow (메타데이터)
- **파일 작업**: shutil, pathlib

### 5.5 데이터 저장
- **프로파일**: `data/profiles/*.json`
- **매니페스트**: `data/manifests/*.json`
- **설정**: `config/config.yaml`

## 6. 사용자 워크플로우

### 6.1 기본 워크플로우
```
1. 웹 브라우저에서 앱 접속 (localhost:5000 또는 close-ai.iptime.org:5000)
2. "폴더 선택" → 정리할 폴더 경로 입력
3. "스캔" → 파일 목록 로드
4. "프로파일 선택" → 기존 프로파일 선택 또는 새로 만들기
5. "AI 분석 시작" → 프로파일 기준으로 파일별 분류 + 리네이밍 (실시간 진행)
6. "미리보기" → 변경 계획 확인, 수동 조정 가능
7. "실행" → 파일 이동/복사 실행
8. "완료" → 결과 요약
```

### 6.2 프로파일 생성 워크플로우
```
1. 프로파일 관리 화면 접근
2. "새 프로파일" 클릭
3. 프로파일 이름/설명 입력
4. 폴더 목록 정의 (폴더명 + AI용 설명)
5. 분류 프롬프트 작성 (AI에게 보낼 지시문)
6. 리네이밍 패턴 설정 (옵션)
7. "저장"
```

## 8. AI 프롬프트 설계

### 8.1 프롬프트 구성 원리
프로파일의 커스텀 프롬프트를 AI에 전달할 때 다음 템플릿으로 감싸서 전송합니다:

#### 이미지 파일용 System 프롬프트
```
당신은 파일 분류 AI입니다. 이미지를 보고 분석하여 반드시 JSON으로만 답하세요.
```

#### 이미지 파일용 User 프롬프트
```
[사용자 프로파일 프롬프트]
{profile.prompt}

현재 파일명: {filename}
사용 가능한 폴더와 설명:
{폴더별 name: description 목록}

반드시 아래 JSON 형식으로만 답하세요:
{"folder": "폴더명", "new_name": "새파일명 또는 null", "description": "한줄 설명"}
```

#### 문서 파일용 User 프롬프트
```
[사용자 프로파일 프롬프트]
{profile.prompt}

현재 파일명: {filename}
문서 내용 (처음 1000자):
{content}

사용 가능한 폴더와 설명:
{폴더별 name: description 목록}

반드시 아래 JSON 형식으로만 답하세요:
{"folder": "폴더명", "new_name": "새파일명 또는 null", "description": "한줄 설명"}
```

### 8.2 프롬프트 설계 원칙
- **프로파일 프롬프트가 핵심**: 사용자의 커스텀 지시가 가장 중요
- **폴더 설명 제공**: 각 폴더에 AI용 설명을 붙여 AI의 이해도 향상
- **단순 JSON 출력**: 항상 3개 필드만 요청 (folder, new_name, description)
- **fallback**: JSON 파싱 실패 시 텍스트에서 폴더명 추출

### 8.3 리네이밍 패턴 처리
```
패턴: "{folder}_{description}"
변수 치환:
  {folder}      → AI가 선택한 폴더명
  {description} → AI가 생성한 설명 (파일명에 안전한 형태로 변환)
  {date}        → 파일 수정일 (YYYYMMDD)
  {original}    → 원본 파일명 (확장자 제외)

예시:
  패턴: "{folder}_{description}"
  결과: "명작_용을_그린_판타지_일러스트.jpg"

  패턴: "{date}_{description}"
  결과: "20240315_제주도_해변_풍경.jpg"

  패턴: "{original}_{folder}"
  결과: "IMG_1234_여행사진.jpg"
```
